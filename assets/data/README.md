# World basemap

`world-countries.geojson` contains the original Natural Earth 110m country
boundaries. GeoJSON is used directly instead of decoding TopoJSON arcs, which
keeps country borders intact at the antimeridian. Natural Earth does not
require attribution, so no source note is rendered in visualizations.

Natural Earth terms of use: https://www.naturalearthdata.com/about/terms-of-use/
